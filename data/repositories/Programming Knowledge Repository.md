Programming Knowledge Repository

Purpose

This document defines the core programming concepts expected of software engineers across Java, Python, and C#. It is intended to help an AI Interview Assistant generate relevant interview questions based on the candidate's experience level, resume, and job description.

The assistant should use this document to:

Identify important programming topics.
Generate conceptual, practical, debugging, and scenario-based interview questions.
Adjust question depth according to experience level.
Avoid focusing only on syntax or language trivia.

Guidance for the OnBoarding Assistant

When using this repository:

Prioritize the programming language(s) explicitly required by the JD and reflected in the candidate's resume.
Adjust question depth based on the candidate's experience rather than relying only on difficulty labels.
Prefer practical, scenario-based, debugging, and design-oriented questions over language trivia.
Personalize questions by referencing the candidate's projects, frameworks, or achievements where appropriate.
Cover both language-specific concepts and universal software engineering principles to provide a balanced assessment.
